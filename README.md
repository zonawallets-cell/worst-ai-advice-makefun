A program that writes one line of the worst possible advice an AI could give to `/output/entry.txt` for make.fun's Worst AI Advice bounty. Pure Python stdlib, deterministic — two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to change where `entry.txt` is written (default `/output`).
